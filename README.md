## 👤 About

I'm **Abhishek Kumar T**, a final-year Computer Science Engineering student and aspiring Full Stack Developer. I build practical projects with Python, Flask, REST APIs, SQL, and machine learning, and I'm learning system design along the way.
<br>
I'm currently building an **AI-Powered Email Spam Detection & Threat Analysis** system in Flask. It connects to Gmail through OAuth 2.0 and classifies messages into six categories: spam, phishing, malware, promotions, newsletters, and legitimate mail. The default 90% RoBERTa + 10% ensemble predictor measured **97.96% accuracy and 97.84% macro F1** on a frozen 2,055-email holdout. RoBERTa-only measured 98.00% accuracy, and the ensemble-only path measured 97.47%. Optional on-device explanations use Ollama when it is available locally and are skipped when it is not.
<br>
